# もじ起こしライブ

日本語の音声を、その場で文字起こしするPWA（ホーム画面に追加できるWebアプリ）です。
オフラインエンジンはブラウザの中で完結し、音声が端末の外に出ることはありません。

## 使い方

1. このページを Safari / Chrome で開き、「ホーム画面に追加」するとアプリのように起動できます。
2. 「エンジンを準備する」を押すと、音声認識モデル（約170MB）を初回だけダウンロードして端末にキャッシュします。2回目以降は機内モードでも動きます。
3. 「録音をはじめる」で話すと、確定した文（黒）と認識中の文（グレー）が分かれて表示されます。
4. 音声ファイル（講義の録音など）を取り込んで文字起こしすることもできます。
5. テキストはコピー／.txt保存ができます。「簡易整形」でフィラー除去と句読点付け、「AIで整文」（自分のAPIキーを設定した場合のみ）で文脈からの誤り修正ができます。

## プライバシー

- オフラインモード: 音声もテキストも端末内で処理します。音声そのものは保存されません（録音中、再認識のためにメモリへ一時保持するだけです）。
- クラウドモード（任意）: ブラウザの音声認識機能を使うため、音声がブラウザ提供元（SafariではApple）のサーバーで処理されます。画面にも明記しています。
- AI整文（任意）: あなたが設定したAPIエンドポイントにだけテキストを送ります。APIキーは端末のブラウザ内にのみ保存され、同梱されていません。

## 技術メモ

- 認識エンジン: sherpa-onnx WebAssembly（SIMD版、v1.13.2）
- 実行時メモ: このWASMビルドはスレッド実行に SharedArrayBuffer（crossOriginIsolated）を必要とします。GitHub Pages は COOP/COEP ヘッダを付けられないため、Service Worker が応答に COOP/COEP を付与し、初回アクセス時に一度だけ自動で再読み込みして分離モードを有効化します（coi-serviceworker と同方式）。
- モデル（選択式、いずれも Silero VAD と併用）:
  - 高精度（既定）: Parakeet 日本語専用（NeMo TDT-CTC 0.6B int8、約656MB）。複数モデルの同一サンプル比較で最も高精度だった。公式WASMパッケージはないが、同梱ランタイムの nemoCtc 経路で動くことを実測して採用。
  - 軽量： ReazonSpeech Zipformer トランスデューサ（int8、約170MB）。メモリ・容量に制約のある機種向け。
- モデルファイルはリポジトリに含めず、初回起動時に Hugging Face 等から取得して Cache Storage に保存します。取得時に SHA-256 ハッシュで同一性を検証します（公式WASMパッケージ同梱モデルとバイト単位で一致することを確認済み）。
- 処理はすべて端末内（＋任意でASRクラウド/API）です。GitHub Pages は静的ホスティングのみで、サーバー側処理は行いません。
